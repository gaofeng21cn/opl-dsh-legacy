# Agent Note: Independent session directories and project membership

Status: implemented

[English](2026-09-20-independent-session-projects.md) | 中文

## 问题

用户需要在选择项目之前使用完整 Agent 会话，也需要整理对话而不破坏文件相对路径。独立的普通聊天入口施加了不符合此工作流的能力限制。

## 决策

全局“新会话”分配唯一的 Host 任务目录并使用正常 Agent 配置。项目行创建会话使用项目目录。项目外会话直接作为侧边栏条目显示。会话菜单可移入已有项目、新登记的目录，或移到项目外。输入区显示实际工作目录。

归档当前会话会清除选中状态并欠下一次替代。该替代与启动后的首次选中一样，在选中时不新开导航世代、也不激活会话界面：用户已有的导航或全局面板不受影响，进行中的用户导航拥有结果，其失败会重新欠下这次落地；被取代的导航在取消时即释放主张，而不是等其创建结束。因此归档手势不会停留在仅能选择工作区的首屏。

工作区域版本 2 保存按 Session 标识索引的可选 sessionPlacements：项目 id 表示显式归属，null 表示明确位于项目外，缺失条目保留旧目录记账。一次持久化写入改变归属，两个分组投影均跟随更新。Session 头、文件和日志保持不变，Agent 运行期间也如此。目标项目内的新会话使用该项目目录；移入会话继续使用原目录。分叉继承当前项目归属与原 cwd。

## 考虑过的替代方案

**随侧边栏移动搬文件或改变 cwd。** 已有相对路径、运行进程与记录上下文将指向不同位置。保留 cwd 能维持这些引用。

**共用一个通用聊天目录。** 无关会话会共享文件与名称。为每次新建会话分配独立目录可避免这种冲突。

**单独的无工具聊天模式。** 这会增加创建选项并阻止正常 Agent 工作。本决策取代[普通聊天入口](2026-09-20-plain-chat-entry.zh.md)的入口策略。已有持久化聊天预设仍可读取以保持兼容；新会话使用正常预设。

## 影响

项目归属用于组织，不代表文件系统隔离或权限撤销。移出项目仍通过原 cwd 访问文件。移除项目不删除文件或对话。归档后独立目录仍保留在 Host home 下。仅登记项目时需要选择目录；归属写入失败时会话仍可重试。旧版程序不理解显式归属，升级后不支持使用旧版编辑项目成员关系。

## 测试

聚焦的控制器、注册表、导航与浏览器测试覆盖独立目录、重试保留、移动、重启和已有 Session 兼容。免密钥 Web 组合测试运行正常 Agent 能力，并检查移动项目后相对文件仍存在。供应商认证和真实模型质量不在本次变更范围内。
